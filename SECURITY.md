This policy defines the scope, reporting process, and disclosure expectations for security vulnerabilities in the Standardised Country Colours mod.

Use this table to indicate which project versions currently receive security maintenance.

| Version | Distribution Channel | Supported |
|---------|--------------------|-----------|
| Latest version | GitHub Releases | ✅ |
| Latest version | Unofficial third-party distribution channels | ❌ |
| Preceding versions | Any distribution channel | ❌ |

## 🚨 Reporting a Vulnerability

Please do not disclose suspected vulnerabilities publicly before maintainers have had an opportunity to validate and remediate them.

To report a vulnerability:
- [GitHub Security Advisories](https://github.com/hmlendea/vic3-standardised-country-colours/security/advisories)
- Contact the maintainers directly

## 📌 Scope

The original maintainers are not responsible for changes, modifications, or security issues introduced by downstream forks.

The subsequent report categories are in scope for this repository:
- Malicious content embedded in the distributed mod archive
- Supply chain compromise of the published release assets
- Definitions that cause the game to fail to load or to corrupt a playthrough

The subsequent categories are out of scope unless explicitly stated to the contrary:
- Vulnerabilities in the Victoria 3 game engine or its launcher
- Issues in the distribution or hosting platforms
- Social engineering or phishing targeting users
- Denial of service against distribution platforms

## 📢 Disclosure Policy

This project follows coordinated disclosure:
1. Vulnerabilities are investigated privately.
2. A remediation plan is prepared and validated.
3. Public disclosure is published after a fix, mitigation, or agreed risk decision is available.
4. Credit is attributed in accordance with reporter preference and project policy.
