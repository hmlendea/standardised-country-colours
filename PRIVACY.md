## 🔎 What This Document Covers

This document describes how Standardised Country Colours at https://github.com/hmlendea/vic3-standardised-country-colours manages personal data. It covers the application conduct and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

This document covers the mod's local game definitions and does not cover Victoria 3, its launcher, distribution platforms, or other software operated by third parties.

## 📥 Data We Handle

### Data Provided to the Application

- The mod does not request personal data from players.

### Data Generated or Collected by the Application

- The mod does not automatically generate or collect personal data, telemetry, diagnostics, or usage data.

### Data Received from Integrations

- The mod has no integrations and receives no personal data from third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- The mod supplies country colour definitions to Victoria 3 — no personal data is involved.

## 🗄️ Storage, Retention, and Deletion

The mod is a set of game definitions installed locally or obtained through a distribution platform. It does not store personal data, so the project has no personal-data retention period or deletion mechanism. Storage, retention, and deletion of data handled by Victoria 3, its launcher, or a distribution platform are outside this project's scope.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer or integrations. Users may obtain it through GitHub Releases, as linked in the [README](README.md). Any data those platforms process when users access their services is handled independently under the platforms' own policies and is not sent to or received by the mod.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| GitHub Releases | Distribution of the mod archive | None sent by the mod | https://docs.github.com/en/site-policy/privacy-policies |

## 🛡️ Data Protection and Security

The mod does not handle personal data and is distributed as game definitions rather than an account-based or network service. The project does not operate a service that stores player data. Keep Victoria 3 and the mod updated, and use the distribution platform's own settings for platform data. No system can be guaranteed completely secure.

The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.

## 🔄 Document Changes

Update this document when application data processes, storage, integrations, or deployment responsibilities change. The current version is published at [PRIVACY.md](PRIVACY.md).
